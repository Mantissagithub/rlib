# Roadmap

Complete and verify one milestone before starting the next.
The first eight milestones are implemented and verified.
Milestone 8 covers the tabular update, the Bellman Q operator, and almost-sure convergence of synchronous and asynchronous Q-learning from fresh independent samples.

1. Finite foundations, complete. Real expectation laws, MDP data, stationary randomized policies, and a checked one-state example.
2. One-step operators, complete. Monotonicity for `0 ≤ γ` and sup-norm error bounds with factor `‖γ‖` for any real `γ`.
3. Policy evaluation, complete. Contraction for a fixed policy with `0 ≤ γ < 1` and a unique solution of its Bellman equation on finite state and action types.
4. Optimality, complete. The finite-action Bellman optimality operator is monotone for `0 ≤ γ`, has a sup-norm error bound for any real `γ`, and has a unique fixed point for `0 ≤ γ < 1`. State and action types are finite, and the action type is nonempty.
5. Algorithms, complete. Value iteration converges from every initial value function to the unique Bellman optimality fixed point for `0 ≤ γ < 1`, on finite state and action types with a nonempty action type. Its error to any supplied fixed point is bounded by `‖γ‖ ^ n * ‖v₀ - v‖` for any real `γ`. A deterministic greedy policy exists for any real discount. For `0 ≤ γ < 1`, a greedy policy has a nondecreasing Bellman value relative to the old policy. Concrete policy iteration uses canonical policy evaluation and a fixed greedy choice depending only on the value function. Its values are nondecreasing, and its policies eventually stabilize at a policy whose value satisfies the Bellman optimality equation. These statements do not require a nonempty state type.
6. Returns, complete. Finite trajectories sample actions and successor states under a stationary randomized policy. Expected discounted sums of stored expected rewards satisfy the fixed-policy Bellman recursion and equal its iterates from zero. The finite expectation requires finite state and action types, with no discount bounds or nonempty-type assumptions. Infinite trajectories have absolutely summable discounted rewards for `0 ≤ γ < 1` on finite state and action types. Finite prefix returns converge to their infinite sum. Finite and infinite return norms are bounded by `‖m.reward‖ / (1 - γ)`. Expected finite returns converge as value functions to the canonical policy value, with no nonempty-type assumptions. A canonical infinite trajectory probability law is constructed, and each finite prefix has exactly the finite trajectory law. The construction requires a finite state type with measurable singletons; the prefix identity additionally requires a finite action type with measurable singletons. No discount bounds or nonempty-type assumptions are needed for these laws. For finite state and action types with measurable singletons and `0 ≤ γ < 1`, infinite returns are integrable under the canonical law, and their integrals equal the policy's Bellman value. This result also needs no nonempty-type assumptions.
7. Learning from samples, complete. Nonempty paired reward and successor observations define an empirical MDP with arbitrary real reward means and observed successor frequencies. Empirical expectation and one-step action values equal their sample means. A two-sided Hoeffding bound applies to independent measurable observations in `[0,1]` with a common expectation, without requiring identical distributions. The empirical reward bound assumes normalized rewards in `[0,1]` and the correct common mean. The empirical transition bound assumes independent measurable successors with the model transition law and measurable singletons. Both bounds are pointwise, require no finite state or action type or discount assumptions, and are instantiated on four independent fair Bool coordinates. A reward and successor within one observation may depend on each other. These results provide no simultaneous row bound, data-dependent continuation guarantee, or independence assertion for samples from a policy trajectory.
8. Q-learning, complete. The tabular update changes one state-action entry using a sampled reward and successor. The Bellman Q operator is the expected target for a sampled successor and the stored mean reward. In an empirical MDP it averages the targets from paired observations. For finite states and finite nonempty actions it contracts and has a unique fixed point when `0 ≤ γ < 1`. A sweep with exact Bellman targets that visits every entry contracts by `1 - α * (1 - γ)` for constant step size `0 < α ≤ 1`. Sequences of complete sweeps converge to the Bellman Q fixed point, even when visit order varies. A sampled update differs from the exact Bellman update only at the visited entry, by the step size times the gap between the sampled and exact targets, for any real step size and discount. When the successor is drawn from the model transition law with the stored mean reward, the visited entry equals the exact Bellman update in expectation. Every sampled update is an exact Bellman update with its realized target error added. For `0 ≤ α ≤ 1`, `0 ≤ γ < 1`, and target errors at most `ε ≥ 0`, a complete sweep contracts the distance to the Bellman Q fixed point by `1 - α * (1 - γ)` down to the floor `ε / (1 - γ)`. After `n` complete sweeps the distance is at most `(1 - α * (1 - γ)) ^ n` times the initial distance plus `ε / (1 - γ)`. A nonnegative real sequence satisfying `x (n + 1) ≤ (1 - a n) * x n + a n * d n`, with `a n ∈ [0, 1]` not summable and `d n → 0`, converges to zero. Stochastic convergence for sampled updates, where errors average out instead of being bounded, remains future work. Synchronous Q-learning, which updates every entry at each step, converges to the Bellman Q fixed point when its step sizes lie in `[0, 1]` and are not summable, `0 ≤ γ < 1`, and its realized target errors tend to zero. A sequence with `W (n + 1) = (1 - a n) * W n + a n * w n` tends to zero under the same step conditions when the partial sums of `a n * w n` converge, possibly conditionally. On a probability space with a filtration, noise `w n` that is measurable at time `n + 1`, bounded almost surely, and has zero conditional mean given time `n` has almost surely convergent partial sums of `α n * w n` when `α n ^ 2` is summable. Synchronous Bellman Q iterations also converge when target errors need not vanish but their step-weighted partial sums converge for every entry. With observed rewards bounded by `R`, synchronous Q-learning tables stay within `max ‖q₀‖ (R / (1 - γ))` in sup norm. Sampled synchronous Q-learning converges almost surely to the Bellman Q fixed point when rewards are bounded, step sizes in `[0, 1]` are not summable but have summable squares, `0 ≤ γ < 1`, and each realized target error is measurable at the next time with zero conditional mean given the current time. That condition is derived from a sampling model: each step's observations are measurable at the next time, independent of the current information, have the model's mean reward, and have the model's transition law as successor law. The state type then needs measurable singletons. Under this model synchronous Q-learning converges almost surely. Bellman Q iterations with per-entry step sizes converge when every entry's step sizes lie in `[0, 1]` and are not summable, the iterates are bounded, and each entry's step-weighted target errors have convergent partial sums. With target errors bounded by `E`, the distance to the fixed point stays within `max ‖q₀ - r‖ (E / (1 - γ))`. Asynchronous Q-learning, which updates only the visited entry from one observation, is this iteration with the step size at visits and zero elsewhere. Its tables stay within `max ‖q₀‖ (R / (1 - γ))` for rewards bounded by `R`, and it converges when every entry's visit step sizes are not summable and its visit-weighted target errors have convergent partial sums. With visits chosen from current information, fresh independent samples with the model's mean reward and transition law, bounded rewards, step sizes in `[0, 1]` with summable squares, and almost surely non-summable visit step sizes for every pair, asynchronous Q-learning converges almost surely to the Bellman Q fixed point.
9. Learning guarantees, partial. Prove sample-complexity or regret bounds for named algorithms under stated MDP assumptions. The first target is model-based Q-value estimation with a generative model: solve the empirical MDP built from `N` samples per state-action pair. For a discount in `[0, 1)`, the Bellman Q fixed points of two models differ by at most the gap between their Bellman Q operators at one fixed point, divided by `1 - γ`. Hoeffding's bound holds for independent observations bounded by `c > 0` with a common mean, with exponent `-(n + 1) * ε ^ 2 / (2 * c ^ 2)`. With `n + 1` independent samples per pair whose rewards are bounded by `R > 0` with the model's mean and whose successors have the model's transition law, the empirical Bellman Q operator at a fixed table `q` is within `ε` of the model's in sup norm except with probability at most `|S| * |A| * 2 * exp (-(n + 1) * ε ^ 2 / (2 * (R + γ * ‖q‖) ^ 2))`. With rewards bounded by `R > 0` and `n + 1 ≥ 2 * R ^ 2 * log (2 * |S| * |A| / δ) / (ε ^ 2 * (1 - γ) ^ 2)`, the Bellman Q fixed point of the empirical MDP is within `ε / (1 - γ)` of the model's except with probability at most `δ`. This bound is not minimax optimal in `1 - γ`. Greedy policy of the estimate (Agarwal, Jiang, Kakade, and Sun, Lemma 1.11): if a Bellman Q fixed point `q*` gives `V* = max_a q*`, then `V*` dominates every stationary policy, and the greedy policy of any table within `ε` of `q*` has value at least `V* - 2 ε / (1 - γ)` at every state; so the greedy policy of the empirical Q fixed point is within `2 ε / (1 - γ) ^ 2` of optimal except with probability at most `δ`. Toward variance-aware bounds: Bernstein's inequality for independent observations within `M` of a common mean with variance at most `σ²`, in tail form `2 exp (-N ε ^ 2 / (2 σ ^ 2 + 2 M ε / 3))` and high-probability form `√(2 σ ^ 2 log (2 / δ) / N) + 2 M log (2 / δ) / (3 N)`; the moment generating function bound uses `exp u - 1 - u ≤ u ^ 2 / (2 (1 - c / 3))` for `u ≤ c < 3`. Total variance (Lemma 2.12 of the book by Agarwal, Jiang, Kakade, and Sun): with rewards in `[0, 1]`, `(I - γ P^π)⁻¹ Var_P (V^π) ≤ 1 / (1 - γ) ^ 2`, proved by checking that `1 / (1 - γ) ^ 2 - (P V^π) ^ 2` is a supersolution, and `(I - γ P^π)⁻¹ √(Var_P (V^π)) ≤ √(1 / (1 - γ) ^ 3)`, proved with one-step Jensen; the book's `√(2 / (1 - γ) ^ 3)` follows. Bernstein's inequality now allows zero variance. Component-wise bounds (Lemma 2.5): for MDPs with the same rewards, `(I - γ P̂^{π̂*})⁻¹ γ (P - P̂) V* ≤ Q* - Q̂* ≤ (I - γ P̂^{π*})⁻¹ γ (P - P̂) V*`, proved by comparison with sub- and supersolutions. Lemma 2.10: with `N` independent successors per pair and the true rewards, for `v` with values in `[0, B]`, with probability at least `1 - δ`, `|(P - P̂) v| < √(2 log (2 |S| |A| / δ) / N * Var_P (v)) + 2 B log (2 |S| |A| / δ) / (3 N)` at every pair. Theorem 2.6 (value estimation): with probability at least `1 - δ`, `‖Q* - Q̂*‖∞ ≤ γ √(c L / ((1 - γ) ^ 3 N)) + c γ L / ((1 - γ) ^ 3 N)` with `L = log (c |S| |A| / δ)` and the explicit constant `c = 12`. The proof splits `δ` over a Bernstein event for `V*` and Hoeffding events for `V*` and `(V*) ^ 2`, transfers variances as in Lemma 2.13 using the fixed-policy simulation bound, bounds both sides of Lemma 2.5 with the total variance lemma in the empirical MDP, and simplifies the constants with `H ^ 2 u √u ≤ (u H ^ {3/2} + H ^ 3 u ^ 2) / 2`. Combined with Lemma 1.11, the greedy policy of `Q̂*` is within `2 / (1 - γ)` times that bound of optimal. The sharper sub-optimality claim of Theorem 2.6, that the greedy policy is within `γ √(c L / ((1 - γ) ^ 3 N))` once `N ≥ 1 / (1 - γ) ^ 2`, is not formalized; the book cites Agarwal, Kakade, and Yang (2020) for it, whose proof uses absorbing MDPs and a leave-one-out argument. Other possible targets are sample complexity of Q-learning itself, and regret bounds.
10. Policy optimization toward PPO and GRPO, complete. This milestone formalizes the mathematics behind PPO and GRPO for finite MDPs. It does not claim that PPO or GRPO converge in general, since no such theorem is known. Planned steps, in order: advantages of a stationary policy; discounted state visitation; the performance difference lemma; the PPO clipped surrogate objective and its pessimism; GRPO's group-relative advantage and its KL estimator; softmax policies and the policy gradient theorem; the trust-region policy improvement bound; generalized advantage estimation; and, optionally, convergence of exact softmax policy gradient and natural policy gradient. Done so far: a stationary policy's action values average to its state value under its own action choice, its advantages average to zero, and its action values satisfy their own Bellman equation. Performance difference lemma: for a discount in `[0, 1)`, the value of a policy `π'` minus the value of `π` is the value of `π'` in the MDP whose rewards are the advantages of `π`. A policy whose expected immediate reward is nonnegative at every state has nonnegative value, so nonnegative expected advantage at every state implies improvement everywhere. A policy has no action with positive advantage exactly when its value satisfies the Bellman optimality equation, and then it is at least as good as every stationary policy. Discounted visitation of a state is `1 - γ` times the policy's value when the reward is one at that state and zero elsewhere. It is nonnegative and sums to one. For any reward, `1 - γ` times the policy's value is the visitation average of the expected reward, and `1 - γ` times the gain of `π'` over `π` is the visitation average under `π'` of the expected advantage of `π`. PPO clipped surrogate: the clipped term `min (ρ * Â) (clip ρ (1 - ε) (1 + ε) * Â)` never exceeds `ρ * Â`, equals it for `ρ ∈ [1 - ε, 1 + ε]`, and is constant once `ρ ≥ 1 + ε` with `Â ≥ 0` or `ρ ≤ 1 - ε` with `Â ≤ 0`. Importance weighting by `q / p` turns expectations under `p` into expectations under `q` when `p` covers the support of `q`. The clipped surrogate never exceeds the surrogate, which equals the old policy's visitation average of the new policy's expected advantage. Relating the surrogate to the true gain needs the trust-region bound. GRPO: group-relative advantages `(r i - mean r) / std r` sum to zero, have mean square one when rewards differ, and are invariant under positive affine changes of the rewards. The KL estimator `x - log x - 1` is nonnegative on positive ratios, vanishes only at one, and has expectation equal to the KL divergence when both distributions share their support, which proves Gibbs' inequality in that case. The GRPO objective for one group never exceeds the average importance-weighted group-relative advantage for a nonnegative penalty weight, and is zero when all ratios are one. Policy gradient theorem: if the action probabilities of policies converge, their values and discounted visitations converge. If the action probabilities of a family of policies `π t` are differentiable at `t₀` with derivatives `π'`, the value is differentiable at `t₀` with derivative `(1 - γ)⁻¹ * ∑ s, d s * ∑ a, π' s a * A s a`, equivalently with the action values `Q` in place of the advantages `A`. The proof uses the performance difference lemma and needs no matrix inverse. Softmax policies: moving the scores in a direction `u` changes each action probability at rate `π a * (u a - ∑ b, π b * u b)` and the value at rate `(1 - γ)⁻¹ * ∑ s, d s * ∑ a, π a * u s a * A s a`, so the partial derivative with respect to the score of `a` at `s` is `(1 - γ)⁻¹ * d s * π a * A s a`. Trust-region bound: switching from `π` to `π'` moves the discounted visitation in `ℓ¹` by at most `γ / (1 - γ)` times the new visitation average of the `ℓ¹` distance between the action distributions. If the expected advantage of `π` under `π'` is at most `ε` in absolute value and that distance is at most `δ` at every state, `1 - γ` times the gain of `π'` is at least the surrogate objective minus `γ / (1 - γ) * ε * δ`. Generalized advantage estimation sums temporal-difference errors along a sampled trajectory with weights `c ^ l`, where `c = γ * λ`. It is the first temporal-difference error for `λ = 0` and telescopes to the discounted return plus `γ ^ n` times the final value minus the start value for `λ = 1`. With the exact policy value, its expectation after taking an action and following the policy is that action's advantage for every `λ` and horizon. Natural policy gradient (Agarwal, Kakade, Lee, and Mahajan 2021): the update `θ ← θ + η / (1 - γ) * A` raises the value at every state by at least `(1 - γ) / η` times the rise in the log-normalizer, so values never decrease. With rewards in `[0, 1]`, `θ⁽⁰⁾ = 0`, and `η > 0`, their Theorem 16 holds: after `T` steps the gap to any policy under any start distribution `ρ` is at most `log |A| / (η T) + 1 / ((1 - γ) ^ 2 T)`. Exact softmax policy gradient (Mei, Xiao, Szepesvári, and Schuurmans 2020), with rewards in `[0, 1]`: values lie in `[0, 1 / (1 - γ)]` and advantages in `[-1 / (1 - γ), 1 / (1 - γ)]`; policies within `δ` in `ℓ¹` at every state have values within `δ / (1 - γ) ^ 2` and advantages within `(1 + γ)` times that; moving softmax scores by `t * u` with `|u| ≤ K` moves each action distribution by at most `2 K |t|` in `ℓ¹`; along such a line the value at `t ≥ 0` is at least the linear prediction minus `3 K ^ 2 t ^ 2 / (1 - γ) ^ 3`; so the weighted value satisfies Lemma 7's quadratic bound `V θ' ≥ V θ + ⟪∇ V θ, θ' - θ⟫ - 4 / (1 - γ) ^ 3 * ‖θ' - θ‖ ^ 2`. Gradient domination (Lemma 8): weight start states by `μ`; the gradient with respect to the score of `a` at `s` is `(1 - γ)⁻¹ * d s * π a * A s a` with `d` the `μ`-weighted visitation. If a deterministic policy `b` has probability at least `c > 0` under `π` and its `ρ`-weighted visitation is at most `C` times `d`, its `ρ`-weighted gain over `π` is at most `C / c` times the sum over states of the gradient entries at `b` in absolute value, and when that gain is nonnegative its square is at most `(C / c) ^ 2 * |S|` times the squared gradient length. Rate (Theorem 4): with step `η = (1 - γ) ^ 3 / 8` each step raises `V (μ)` by at least `(1 - γ) ^ 3 / 16` times the squared gradient length; a nonincreasing sequence that starts at most `1 / κ` and drops by at least `κ * δ ^ 2` while nonnegative is at most `1 / (κ * (t + 1))`; so if `μ > 0`, `b` is an optimal deterministic policy, and every iterate gives `b` probability at least `c > 0`, then for every `t ≥ 1`, `V* ρ - V θ_t ρ ≤ 16 |S| / (c ^ 2 (1 - γ) ^ 6 t) * D ^ 2 * M` whenever `d*_μ ≤ D * μ` and `1 ≤ M * μ`, which are the sup norms of the paper. Asymptotic convergence (Agarwal et al., Theorem 10), in progress. Done: a softmax step that adds `κ * π a * A a` with `κ ≥ 0` to the scores, where `A` averages to zero under `π`, gives a policy under which `A` averages to at least zero, because `y * exp (κ * y) ≥ y`; so exact softmax policy gradient with any step `η ≥ 0` and weights `μ ≥ 0` raises the value at every state, and with rewards in `[0, 1]` the values, action values, and advantages of the iterates converge. With a step `0 < η ≤ (1 - γ) ^ 3 / 8` each step raises `V (μ)` by at least `η / 2` times the squared gradient length, so the squared gradient lengths are summable, every gradient entry tends to zero, and `π_t (a | s) * A_t (s, a) → 0` wherever `μ s > 0`. Lemma C.11: if the advantage of an action at a state with `μ s > 0` stays below `-ε < 0`, its score tends to `-∞`; the proof bounds the total of `1 / Z_t` by the finite descent of that score, which keeps every score bounded below, hence above since the scores keep their sum, contradicting `Z_t → ∞`. Theorem 10 itself: with `μ s > 0` for every state and `0 < η ≤ (1 - γ) ^ 3 / 8`, no action keeps a positive limiting advantage. The proof follows the paper: probabilities of actions with nonzero limiting advantage vanish (Lemma C.5); once an action with zero limiting advantage falls below a positive-advantage action `a⁺` it stays below (Lemma C.8); the remaining zero-advantage actions stay above `a⁺`, lose probability-weighted advantage in total, and so have bounded scores; then every probability at the state tends to zero, which is impossible. So the limit of the values satisfies the Bellman optimality equation and is at least the value of every stationary policy. Mei et al.'s Lemma 9: if the optimal deterministic policy `b` has the unique optimal action at every state, the limit of the values is the value of `b`, every other action has negative limiting advantage and so vanishing probability, and the probability of `b`'s action tends to one; hence there is `c > 0` below which it never falls. The paper's region argument proves more (eventual monotonicity of that probability), which the rate does not need. With this `c`, Theorem 4 holds unconditionally. The uniqueness of the optimal action is implicit in the paper's positive gap `Δ*`. Milestone 10 is complete.

## Probability representation

Use mathlib's `PMF` for transitions and policies. Its normalization and probability operations already have proofs.
A custom `FiniteDist` would duplicate those facts and require conversion lemmas before using measure-theoretic results.
Keep real finite expectation in `Rlib.Probability.Expectation` so MDP proofs do not repeat conversions from `ℝ≥0∞` to `ℝ`.

The MDP stores transitions and expected rewards without finite-type assumptions or a discount parameter.
Each operator requests the finite instances it uses. Theorems request discount bounds only when their conclusions need them.
Rewards depending on the sampled next state and unavailable actions need separate design decisions before introduction.
